# Changelog

## 0.1.0 - 2026-10-25

- Initial pre-stable release for Laravel 10–13 and PHP 8.1–8.4.
- Added UUID, ULID, and integer schemas; tenant/global uniqueness; foreign-key integrity; and additive adoption migrations.
- Added registry synchronization, cached permission resolution, Gate/Blade/middleware integration, typed events, transactional actions, guardrails, auditing, and session revocation.
- Added maintenance jobs, scheduler integration, install/adopt/sync/assign/super-admin/prune/cache/doctor commands, testing helpers, and an opt-in permission-protected management API.
- Added SQLite/MySQL/PostgreSQL CI, static analysis, formatting, Composer audit, and feature coverage for tenancy, caching, guardrails, adoption, commands, jobs, and API isolation.
