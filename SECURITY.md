# Security policy

Report suspected vulnerabilities privately to the package maintainers. Include the affected package version, Laravel/PHP versions, a concise impact description, and reproduction steps. Do not include production credentials or personal data in reports.

Use GitHub's private vulnerability reporting for `Mainul12501/uui-role-permission` when it is available. Do not open public issues for security reports.

The management API is disabled by default and applies authentication plus configurable permission middleware when enabled. Treat audit records as security-sensitive data and configure retention to match organizational requirements.
